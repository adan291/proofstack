    LinkedIn

    LinkedIn solo deja leer tus propios datos con una app tuya. Se crea una vez, en unos 5 minutos, y solo funciona con cuentas del EEE y Suiza. Si la tuya no lo es, usa el ZIP: ./proofstack setup --linkedin-zip Basic_LinkedInDataExport.zip.

    1. Abre linkedin.com/developers/apps/new. Como página de empresa elige Member Data Portability (Member) Default Company.
    2. En Products, añade Member Data Portability API (Member).
    3. En Auth, añade la redirect URL http://127.0.0.1:63141/callback.
    4. Copia aquí el Client ID y el Client Secret. Se guardan en tu carpeta de usuario, fuera del repositorio, y solo tú puedes leerlos.

    Trae tu experiencia, formación, skills, idiomas y certificaciones. Se abre LinkedIn en otra pestaña: pulsa Permitir y vuelve aquí. Tus proyectos y evidencias no se tocan.

      Revisar y publicar

        Ver la web Ver el CV Afinar en el editor completo

        Publicar en GitHub Pages (la primera vez)

        1. Settings → Pages: en Source elige GitHub Actions.
        2. Settings → Variables: crea la variable de repositorio PROOFSTACK_PROFILE con el valor profiles/tu-nombre/profile.yaml.
        3. Settings → Actions → General: marca Allow GitHub Actions to create and approve pull requests, para recibir tus repos nuevos cada lunes.
        4. En la terminal, desde la carpeta del repositorio: 
          git add -A
git commit -m "Mi perfil"
git push
          Tu web quedará en https://<usuario>.github.io/<repo>/ en unos 3 minutos.
